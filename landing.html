把 AI 做好的内容，送到你的墨水屏。

eink-push 面向阅星曈/Yue Xingtong 设备。它能把短内容做成卡片，把长内容做成 Markdown 翻页电子书；当你明确需要 EPUB 时，也能生成带封面的 EPUB。它还能查询书架、阅读进度和书签摘录，把阅读数据重新整理成可读内容。

Decision Route

一句话之后，skill 会先判断形式。

  • 1发到阅星曈：按字数走卡片或 Markdown 翻页电子书。
  • 2明确说卡片：生成 HTML 卡片并推送。
  • 3明确说电子书：整理 Markdown 并推送。
  • 4明确说 EPUB：生成 EPUB，必要时带封面。

Quality Pass

最新脚本把粗糙处收紧了。

  • OK参数早校验：尺寸、Gamma、图片质量、分页参数会给出清楚错误。
  • OK安装审计更完整：会检查 runtime 文件是否和源码漂移。
  • OKEPUB 更顺：保留前言正文，避免重复章节标题。
  • OK测试边界明确：pytest 只收集本仓库测试。

Setup & Safety

安装、凭证和环境都讲清楚。

真正影响体验的不是功能列表，而是首次使用时能不能顺利跑起来。最新 skill 内置环境预检、凭证结构检查、安装漂移审计和离线 smoke test。

环境预检

运行 `python scripts/check_environment.py`，缺依赖时直接给出 fix 命令。

凭证来源

优先 `XTEINK_USERNAME` / `XTEINK_PASSWORD`，再兼容 `YUEXINGTONG_*`，最后 fallback 到 `.credentials.json`。

官方域名

凭证只用于阅星曈官方 API：`api-prod.xteink.cn`。不会写入仓库，也不会传给其他域名。
