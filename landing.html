给 OpenClaw 的阅星曈 Skill

把内容送到你的墨水屏。

让 AI 把摘要、文章、调研资料和读书摘录整理成适合阅星曈阅读的形式。短内容做成卡片，长内容排成电子书，书架和书签也能继续整理。

npx --yes skills add https://github.com/linchuanXu/eink-push -a openclaw -y
开始配置 查看功能

安装后，在对话里说“发到阅星曈”就可以开始使用。

功能

从对话到墨水屏，少一点手动整理。

它不是把文字原样丢给设备，而是先判断内容类型，再选择适合墨水屏阅读的呈现方式。

A

短内容卡片

摘要、清单、结论和摘录，会整理成一眼能读完的墨水屏卡片。

适合快速查看 自动排版
B

长文电子书

文章、报告和长笔记，会排成适合连续阅读的翻页电子书。

适合深读 保留结构
C

EPUB 文件

明确需要 EPUB 时，会生成带封面的电子书文件，适合长期保存。

可收藏 可带封面
D

书签与进度

书架、阅读进度、书签和摘录，可以整理成卡片、笔记或阅读小结。

读书回顾 摘录整理

发送方式

你只需要说清楚想读什么。

  • 1发到阅星曈：让 AI 判断该做卡片还是电子书。
  • 2做成卡片：适合摘要、清单、摘录和临时备忘。
  • 3整理成电子书：适合文章、报告和完整阅读笔记。
  • 4生成 EPUB：明确需要文件时，再生成 EPUB。

体验优化

少解释，多交付。

  • OK自动选择格式：短内容用卡片，长内容用电子书，EPUB 只在你明确需要时生成。
  • OK保留阅读上下文：书签、进度和摘录会按读书场景整理，而不是只列原始数据。
  • OK推送前先排版：内容会先变成适合墨水屏查看的页面，再发送到设备。
  • OK出错时能继续：账号、设备或网络有问题时，会给出下一步处理方式。

配置

先让 Skill 知道该发到哪里。

第一次使用只需要安装 Skill，并完成阅星曈账号和设备绑定。之后就可以在对话里直接发送内容。

安装 Skill

复制页面上的 npx 命令运行即可。安装完成后，OpenClaw 会使用最新的 GitHub 版本。

确认账号

按提示提供阅星曈账号信息。凭证只用于登录和发送到你的设备。

绑定设备

确认设备已经在阅星曈 App 中绑定到同一账号，发送内容时就能接收。

开始使用

让内容在墨水屏上更好读。

安装完成后，把摘要、文章、摘录或调研资料交给 AI，就可以发送到阅星曈。
