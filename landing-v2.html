如果卡在这里

看一眼输出，通常就知道下一步该做什么。

不用猜。现在常见问题基本都会变成清楚的状态提示，按提示处理就行。

看到什么
这是什么意思
接下来做什么
OK
环境或凭证检查已经通过。
可以继续发内容，或者查看书架和书签。
AUTH_OK
账号密码已经能真实登录。
现在就可以开始真实推送。
MISSING
还没有找到可用的账号配置。
补上手机号和密码，或者设置环境变量。
INVALID
账号信息不完整，或者本地凭证文件有问题。
把用户名和密码都补齐，然后再检查一次。
AUTH_FAILED
登录没成功，常见原因是密码不对，或者网络暂时不通。
401 时重新确认账号密码；超时就检查网络后再试。

环境

环境要求

Python 需要 3.10+。如果要生成 Markdown 翻页电子书，还需要 Node.js 18+ 和 npm install marknative。

验证

先离线试一遍

python scripts/smoke_test.py 会先检查卡片、电子书和 EPUB 渲染，不会真的发到设备。

同步

确认装的是最新版本

python scripts/check_installation.py 会提示你当前安装的版本和源码有没有不一致。

如果发不过去，先确认设备已经在阅星曈 App 中绑定到同一个账号。大多数“怎么没到设备上”的问题，都是卡在这里。
