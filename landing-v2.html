Setup Flow

四步完成首次使用。

用户真正会卡住的地方通常不是“不会用”，而是依赖、凭证和设备绑定。这里按当前 skill 的推荐路径排好顺序。

在 OpenClaw 中安装或更新 skill

把提示词发给小龙虾。已经安装过也可以用同一句更新到最新版本。

安装技能 https://github.com/linchuanXu/eink-push，并引导我完成阅星曈账号配置

检查本地运行环境

首次运行前先跑预检。出现 MISSING 或 FAIL 时，按脚本输出的 fix: 命令处理。

python scripts/check_environment.py

准备阅星曈账号凭证

推荐用环境变量；未设置时 skill 会读取本地 .credentials.json。凭证只发往 api-prod.xteink.cn。

python scripts/push_to_device.py --check-credentials --auth

完成一次真实动作

先从简单句开始：推送一段文字、查询书架，或整理一本书的书签。设备需要先在阅星曈 App 中绑定到同一账号。

把这段内容做成墨水屏卡片，推到阅星曈。

Checks

看输出就知道下一步。

最新脚本把常见失败变成了可处理的状态。不要猜，按输出做。

看到的输出
含义
下一步
OK
凭证结构或环境检查通过。
继续推送或查询阅读数据。
AUTH_OK
账号密码已通过真实登录校验。
可以执行真实推送。
MISSING
没有找到环境变量或本地凭证文件。
提供手机号和密码，或设置环境变量。
INVALID
环境变量只配置了一半，或凭证文件缺字段/损坏。
同时补齐用户名和密码，再重跑检查。
AUTH_FAILED
真实登录失败，可能是密码错误或网络问题。
401 时重置凭证；超时则检查网络后重试。

What To Say

这些说法适配当前版本。

刻意避免过度承诺。PDF OCR、日历同步、漫画裁边等不是当前 skill 的核心脚本能力，这页不再把它们写成已上线功能。

卡片

短内容推送

“把这段发到阅星曈”“做成墨水屏卡片”“生成阅读看板卡片”。适合摘要、清单、仪表盘和精选摘录。

电子书

长文连续阅读

“整理成电子书发过去”“把书签整理成阅读笔记”。默认走 Markdown 翻页电子书，适合长内容。

EPUB

明确 EPUB 才触发

“生成 EPUB 发到设备”“推 EPUB，要带封面”。适合图文混排和设备电子书阅读器。

书架

阅读进度

“看一下我的书架”“我最近读了哪些书”。默认 compact 输出，展示书名、进度、时长和最近活跃。

书签

摘录整理

“整理《书名》的书签”“挑几条精彩摘录做成卡片”。未指定书名时先查书架再选择。

调研

搜索后推送

“查一下最新资料，整理成卡片/电子书”。阅星曈推送场景中可联网搜索，并保留引用来源。

Runtime Notes

依赖和同步也有兜底。

开发仓库和实际安装副本可能不一致。最新版本的安装审计已经会比较 runtime 文件，而不只是比较 frontmatter。

环境

Python 与 Node

Python 需要 3.10+。Markdown 翻页电子书路径需要 Node.js 18+ 和 npm install marknative。

验证

离线 smoke

python scripts/smoke_test.py 会验证卡片、Markdown 电子书和 EPUB 渲染，不会推送设备。

同步

安装漂移审计

python scripts/check_installation.py 会提示安装副本是否和源码 runtime 文件不一致。

真实推送前，确保设备已经在阅星曈 App 中绑定到同一账号。未绑定设备时，skill 会提示先绑定设备再重试。
