配置步骤

四步完成初次配置。

配置的关键是三件事：本地环境可用、账号凭证正确、设备已绑定到同一账号。确认完成后，再发送一张测试卡片。

安装或更新 skill

在 OpenClaw 中发送这句话。已经安装过时，也可以用同一句更新到最新版本。

安装技能 https://github.com/linchuanXu/eink-push，并帮我配置阅星曈账号

检查本地环境

初次运行前先检查一遍。如果缺少依赖，脚本会给出对应的处理方式。

python scripts/check_environment.py

配置阅星曈账号

推荐使用环境变量；也可以读取本地 .credentials.json。账号信息只会用于官方接口 api-prod.xteink.cn。

python scripts/push_to_device.py --check-credentials --auth

发送一张测试卡片

可以先从一段短内容开始。发送前，请确认设备已经在阅星曈 App 中绑定到同一账号。

把这段内容做成卡片，发送到阅星曈。

状态说明

根据输出，确认下一步。

检查命令会把常见问题转换成明确的状态。看到对应输出后，按下面的说明处理。

输出
含义
处理方式
OK
环境或凭证检查通过。
可以继续发送内容，或查看书架和书签。
AUTH_OK
账号密码已通过登录校验。
可以进行真实发送。
MISSING
没有找到可用的账号配置。
补充手机号和密码，或设置环境变量。
INVALID
账号信息不完整，或本地凭证文件格式有问题。
补齐用户名和密码后，再重新检查。
AUTH_FAILED
登录校验失败，可能是密码错误或网络异常。
401 时重新确认账号密码；超时则检查网络后重试。

下面这些表达都能对应到当前版本已经支持的能力。

卡片

短内容卡片

“把这段做成卡片，发送到阅星曈”。适合摘要、清单和精选摘录。

电子书

长内容电子书

“整理成电子书”“把书签整理成阅读笔记”。适合需要连续阅读的内容。

EPUB

想要 EPUB 就直接说

“生成 EPUB”“带封面”。明确提出 EPUB 时，会按 EPUB 文件准备。

书架

阅读进度

“看一下我的书架”“我最近读了哪些书”。会整理书名、进度和最近阅读状态。

书签

书签摘录

“整理《书名》的书签”“挑几条摘录做成卡片”。适合回顾和复习。

调研

调研整理

“查一下最新资料，整理成卡片或电子书”。调研结果会带上来源，再整理成适合阅读的版本。

环境

环境要求

Python 需要 3.10+。如果要生成 Markdown 翻页电子书，还需要 Node.js 18+ 和 npm install marknative。

验证

先离线试一遍

python scripts/smoke_test.py 会检查卡片、电子书和 EPUB 渲染，不会发送到设备。

同步

确认装的是最新版本

python scripts/check_installation.py 会提示你当前安装的版本和源码有没有不一致。

如果内容没有出现在设备上，请先确认设备已经在阅星曈 App 中绑定到同一个账号。
