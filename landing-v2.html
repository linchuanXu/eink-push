配置阅星曈 Skill

一条命令，接入阅星曈。

安装后，OpenClaw 就能把对话里的摘要、长文、书签和调研资料整理成适合墨水屏阅读的内容，并发送到你的阅星曈设备。

开始配置 查看介绍
复制命令
npx 安装
npx --yes skills add https://github.com/linchuanXu/eink-push -a openclaw -y

配置步骤

四步完成配置。

你只需要先完成安装，再确认账号和设备。后面的排版、格式选择和推送动作，都交给 Skill 处理。

安装 Skill

复制页面顶部的 npx 命令，在终端中运行。已经安装过时，也可以用同一条命令更新到 GitHub 上的最新版本。

确认阅星曈账号

首次使用时，按 OpenClaw 的提示完成账号确认。账号信息只用于登录阅星曈官方服务和发送到你的设备。

确认设备已绑定

打开阅星曈 App，确认墨水屏设备已经绑定到同一个账号。没有绑定设备时，内容无法接收。

发送第一张卡片

配置完成后，可以先用一段短内容测试。看到设备接收成功后，就可以开始发送文章、摘录和调研资料。

把这段内容做成卡片，发送到阅星曈。

完成确认

安装之后，确认这三件事。

这部分给普通用户看，不需要记状态码。只要确认下面三项，就可以开始发送内容。

安装

命令运行完成

页面上的 npx 命令会从 GitHub 安装当前 Skill。之后有更新，也继续运行同一条命令。

账号

账号可以登录

OpenClaw 会按 Skill 的流程检查账号。账号错误或网络异常时，会提示你重新确认。

设备

设备已绑定

内容会发送到同一账号下的阅星曈设备。没有绑定设备时，请先在 App 里完成绑定。

常用说法

常见入口。

下面这些表达都能对应到当前版本已经支持的能力。

卡片

内容卡片

“把这段做成卡片，发送到阅星曈”。适合摘要、清单和精选摘录。

电子书

翻页电子书

“整理成电子书”“把书签整理成阅读笔记”。适合需要连续阅读的内容。

EPUB

EPUB

“生成 EPUB”“带封面”。明确提出 EPUB 时，会按 EPUB 文件准备。

书架

阅读进度

“看一下我的书架”“我最近读了哪些书”。会整理书名、进度和最近阅读状态。

书签

书签摘录

“整理《书名》的书签”“挑几条摘录做成卡片”。适合回顾和复习。

调研

调研整理

“查一下最新资料，整理成卡片或电子书”。调研结果会带上来源，再整理成适合阅读的版本。

使用建议

把它当成阅读入口，而不是文件工具。

安装完成后，最重要的是说清楚内容和阅读目的。Skill 会按场景选择卡片、电子书或 EPUB。

短内容

先做成卡片

摘要、清单、结论和几条摘录，适合做成卡片。它们会更快出现在设备上，也更适合临时回看。

长内容

交给电子书

文章、报告和完整阅读笔记，适合整理成翻页电子书。阅读节奏会比卡片更稳定。

读书数据

书签可以继续整理

你可以让它查看书架、整理某本书的摘录，或把最近阅读进度做成一份回顾。

如果内容没有出现在设备上，请先确认设备已经在阅星曈 App 中绑定到同一个账号。
