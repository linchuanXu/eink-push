# 首次配置 / 首次推送成功后：功能引导

配置好后，以自然语言向用户展示以下内容。不要照抄，用对话语气呈现，挑 2-3 个最相关的例子重点说，其余可一笔带过。

---

配置好了！凭证读取会优先使用 `XTEINK_USERNAME` / `XTEINK_PASSWORD` 环境变量；如果未设置，就使用本地 `.credentials.json`。这些凭证只用于登录官方阅星曈 API，不会提交到仓库，也不要把它发给别人。

可以先做一个安全检查：

```bash
python scripts/push_to_device.py --check-credentials
```

输出 `OK` 就说明本地凭证结构正常。

如果你想确认账号密码能真实登录，可以运行：

```bash
python scripts/push_to_device.py --check-credentials --auth
```

看到 `AUTH_OK` 就说明登录也正常。真正推送会在设备上创建任务。

正式安装副本里的基础环境检查可以运行：

```bash
python scripts/check_environment.py
```

开发维护验证请回到源码仓库按 README 执行；正式安装副本不包含维护脚本。

---

**把内容推到墨水屏**

随时在对话结束后说「发到设备」，我会自动按字数选格式：

- 资讯卡 / 一屏摘要 → 单张卡片
- 多主题整理 / 简报 → 多张卡片集
- 长文 / 分析报告 / 书 → 翻页电子书
- 明确说 "EPUB" / "epub 格式" → EPUB 电子书

也可以指定格式：
- "帮我搜一下 XX 最新进展，整理成简报发到阅星曈"
- "把这次对话的结论做成一张卡片推过去"
- "写一份 XX 深度报告，做成电子书发到设备"
- "把这份材料做成 EPUB 发到设备"

---

**查你的阅读数据**

我能直接读取你在阅星曈上的阅读记录：

- "我最近在读什么？" → 列出书架进度和阅读时长
- "帮我看看《XX》的书签" → 显示你划过的所有摘录

---

**把阅读数据变成内容推回去**

这是最好玩的部分——从你的书架和书签生成东西，再推回墨水屏：

- "把《XX》的书签做成精选卡片" → 引言排版的书摘卡片集
- "整理《XX》的阅读笔记，做成电子书" → 按章节归整的翻页电子书
- "生成一张阅读看板" → 显示在读 / 已读 / 总时长的仪表盘卡片

---

**重置账号**

如果换号、密码错误，或者想重新登录：

```bash
python scripts/push_to_device.py --reset-credentials
```

然后重新提供手机号和密码即可。如果你使用环境变量，也可以直接更新 `XTEINK_USERNAME` / `XTEINK_PASSWORD`。
